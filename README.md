## Deskripsi Aplikasi
TechMate adalah aplikasi pembelajaran Informatika untuk siswa SMA/SMK yang dikembangkan menggunakan Flutter. Aplikasi ini dirancang untuk membantu siswa mempelajari materi Informatika melalui smartphone dengan tampilan yang sederhana dan interaktif.
TechMate dirancang sebagai media pembelajaran yang dapat digunakan secara offline, sehingga siswa dapat mengakses materi tanpa harus selalu terhubung ke internet.

## Fitur Aplikasi
- Beranda: menampilkan halaman utama dan fitur Lanjut Belajar.
- Materi Pembelajaran: menyediakan materi Informatika yang disusun berdasarkan beberapa topik.
- Video Pembelajaran: menyediakan menu untuk mengakses video pembelajaran.
- Kuis Interaktif: membantu siswa menguji pemahaman melalui aktivitas dan pertanyaan.
- Progres Belajar: menyimpan informasi materi dan slide terakhir yang dipelajari.
- Respons Jawaban: memberikan respons terhadap jawaban benar atau salah pada aktivitas tertentu.

## Materi Pembelajaran
Materi yang dikembangkan dalam TechMate meliputi:
1. Pengenalan Teknologi
2. Sistem Komputer
3. Jaringan dan Internet
4. Keamanan Digital
5. Artificial Intelligence (AI)

## Teknologi yang Digunakan
- Flutter sebagai framework pengembangan aplikasi.
- Dart sebagai bahasa pemrograman.
- Visual Studio Code sebagai editor kode.
- SharedPreferences untuk menyimpan progres belajar secara lokal.
- Git dan GitHub untuk pengelolaan versi dan penyimpanan repositori kode.

## Cara Menjalankan Proyek
1. Instal Flutter SDK dan Visual Studio Code.
2. Unduh atau clone repositori TechMate.
3. Buka folder proyek di Visual Studio Code.
4. Buka terminal pada folder proyek.
5. Jalankan perintah berikut untuk mengunduh dependensi:
   `flutter pub get`
6. Jalankan aplikasi di browser Chrome menggunakan perintah:
   `flutter run -d chrome`
   Aplikasi juga dapat dijalankan pada perangkat Android yang sudah terhubung dan dikonfigurasi untuk pengembangan Flutter.
